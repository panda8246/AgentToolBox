# 初始化提示词

将以下内容复制到新项目的 Agent 对话中，并补全方括号内的信息：

```text
请为当前项目初始化轻量目标管理框架。请在项目根目录创建并填写：
- AGENTS.md
- docs/PROJECT.md
- docs/CURRENT.md
- goals/active/
- goals/archive/
- goals/GOAL-TEMPLATE.md

采用三层结构：
1. PROJECT.md 只记录长期愿景、目的、边界、原则、成功标准与阶段方向。
2. CURRENT.md 是唯一全局当前状态，只列活跃目标、阻塞或待确认事项及最值得做的下一步。
3. 每个独立推进、探索或需要验收的事项使用一个 goals/active/ 下的目标文件；目标分为交付型或探索型，完成后写明结果、验证或结论并移入 goals/archive/。

不要创建空的路线图、架构、历史、决策或任务管理文档；只有内容实际出现且能减少未来理解成本时再新增文档。
不要记录完整聊天过程或敏感信息。文档与可验证代码或配置冲突时，以代码和配置为准。

项目背景：
[填写项目是什么、服务谁、为什么要做]

长期愿景：
[填写希望长期达成的价值]

当前阶段：
[填写当前最重要的阶段]

当前目标或待探索问题：
[填写 0～3 个当前最重要的目标；没有则留空]

已知约束：
[填写时间、预算、隐私、平台、技术等约束]

先给出简短的结构说明，再直接创建文件。不要为了完整性虚构信息；未知内容明确标记为待确认。
```

## 日常续接提示词

```text
请读取 docs/PROJECT.md、docs/CURRENT.md，以及本次相关的 goals/active/ 目标文件。
说明当前要推进的目标、已知进度、阻塞项和下一步；随后只在当前目标范围内开展工作。
有实质进展时更新目标文件和 docs/CURRENT.md；只有长期方向发生变化时才更新 docs/PROJECT.md。
```
