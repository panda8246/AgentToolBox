你正在为此项目初始化 Goal Framework。请先阅读现有的 `AGENTS.md`（如有）、README、配置、主要代码和最近的版本控制状态，再填写 `docs/PROJECT.md` 与 `docs/CURRENT.md`。

规则：
- 不覆盖或删除已有的项目规则；Goal Framework 只使用 `AGENTS.md` 内带有 `GOAL-FRAMEWORK` 标记的受管区块。
- `PROJECT.md` 只记录长期愿景、边界、原则、成功标准和阶段方向；未知信息明确写为“待确认”，不要猜测。
- `CURRENT.md` 是唯一全局当前状态，只记录活跃目标、阻塞或待确认事项及下一步。
- 仅当工作需要独立推进、探索或验收时，在 `goals/active/` 新建目标文件；区分交付型与探索型。
- 活跃目标文件命名为 `YYYY-MM-DD-short-title.md`，日期使用创建日期；完成归档时，重命名为相同格式但日期使用归档日期，再移至 `goals/archive/`。
- 不创建空的路线图、架构、历史、决策或任务管理文档。
- 不记录密钥、令牌、个人隐私或完整聊天记录。

完成后，用简短摘要说明：你从代码中确认的项目事实、尚待确认的内容，以及第一个最值得推进的目标。
